# NKN Atelier

Мультиязычный сайт-портфолио для ателье дизайнера одежды NKN.

## Технологии

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- next-intl (EN/RU/DE)
- Motion (framer-motion)
- shadcn/ui

## Разработка

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Сборка

```bash
npm run build
```

## Деплой на GitHub Pages

Проект настроен для автоматического деплоя на GitHub Pages через GitHub Actions.
