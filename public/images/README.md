# Images Directory

Place your images here:

- `hero.jpg` - Hero section image (recommended size: 1200×1600px). If missing or broken, the site uses a built-in fallback photo until you add your own file.
- Gallery images can be placed here or use external URLs

## Image Requirements

- Hero image: 3:4 aspect ratio recommended
- Gallery images: 3:4 aspect ratio recommended
- Format: JPG, PNG, or WebP
- Optimize images before adding them to reduce file size
